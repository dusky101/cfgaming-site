# The website's docs

What each folder holds. The files are their own index: there's no front page listing them.

| Folder or file | What's in it |
|---|---|
| [ABOUT.md](ABOUT.md) | Why the site exists, who it's for, what it promises and what it never does. Read it first. |
| [phases/](phases/) | Phases not yet finished, one file each (`NN-topic.md`): aim, steps, checks and "For Marc", agreed before the phase starts. |
| [completed/](completed/) | Finished phases: the same files, moved here with their reports added at the end. |
| [handovers/](handovers/) | Each session's handover for the next (`YYYY-MM-DD-topic.md`). |
| [prompts/](prompts/) | The prompt Marc pastes to start that next session, beside its handover (`YYYY-MM-DD-topic.md`). |
| [ideas/](ideas/) | Marc's ideas for later, outside the current phases, one file each (`topic.md`). An idea that becomes a phase moves to `completed/` with it. |

Outside `docs/`: [CREDITS.md](../CREDITS.md) lists every picture's source and licence. The site is stage 27c of CF Gaming's plan, `~/Codingapps/CFMacGaming/handover/plan-27a-27g-website-and-paid-route.md`; the site's own phases are numbered from 01.
